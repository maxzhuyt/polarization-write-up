\section{System Message Variants}
\label{app:sys_msg}

To verify that the choice of system message does not drive the main findings, we tested nine system message phrasings on a held-out model (dolphin-2.9.3-llama-3-8b, 8B) using the \textsc{stance} user-turn template across all 199 topics. Table~\ref{tab:sysmsg_sweep} reports Pearson $r$ between activation-space partisan divergence and GSS partisanship for the full topic set ($r_\text{all}$), public issues only ($r_\text{pub}$), and private-life topics only ($r_\text{priv}$).

\begin{tabular}{lccc}
\toprule
